# CDR QuickLook 1.0.0

Primeira versão pública.

## Recursos

- Miniaturas de documentos CorelDRAW (`.cdr`) no Finder.
- Preview pela barra de espaço sem abrir o CorelDRAW.
- Documentos com várias páginas em uma visualização rolável.
- Janela inicial ampla, semelhante ao Quick Look de PDFs.
- Aplicativo universal para Apple Silicon e Macs Intel.
- Compatível com macOS 12.4 ou posterior.

## Instalação

Baixe o arquivo DMG, arraste **CDR QuickLook.app** para **Applications** e abra
o aplicativo uma vez para registrar as extensões.

Esta compilação é assinada ad-hoc e não é notarizada. Caso o macOS bloqueie a
primeira abertura, clique com o botão direito no aplicativo e escolha
**Abrir**.

## Limitação conhecida

A qualidade da imagem depende da prévia incorporada pelo CorelDRAW. Documentos
antigos sem PNG ou JPEG incorporado podem não produzir uma visualização.
