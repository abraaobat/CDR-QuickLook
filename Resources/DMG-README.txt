CDR QuickLook
=============

INSTALAÇÃO

1. Arraste “CDR QuickLook.app” para o atalho “Applications”.
2. Abra o aplicativo pela pasta Aplicativos uma vez.
3. Selecione um arquivo .cdr no Finder e pressione a barra de espaço.

Se o macOS bloquear a primeira abertura, clique com o botão direito no
aplicativo, escolha “Abrir” e confirme. Esta versão pública é assinada
localmente (ad-hoc), mas ainda não é notarizada pela Apple.

O CorelDRAW permanece como aplicativo padrão para abrir e editar os arquivos.
